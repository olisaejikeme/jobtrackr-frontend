# JobTrackr Frontend

A clean and minimal frontend for tracking job applications, built with React and Tailwind.

## Live App
[https://jobtrackr-frontend-tan.vercel.app](https://jobtrackr-frontend-tan.vercel.app)

> **Demo Disclaimer:** > This project is hosted on free-tier infrastructure. If the site feels unresponsive at first, the backend is likely waking up from a "Cold Start." This process can take **50-90 seconds**. Additionally, this dashboard is currently optimized for **Desktop View**.

---

## Tech Stack
* **Framework:** React (Vite)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Routing:** React Router

---

## Features
* **Authentication:** Secure login and session management.
* **Dashboard Overview:** Visual summary of your job search progress.
* **Application Tracking:** Full CRUD (Create, Read, Update, Delete) for job applications.
* **UI/UX:** Clean, minimal interface with toast notifications and loading states.

# JobTrackr Frontend

A clean and minimal frontend for tracking job applications, built with React and Tailwind.

## Live App

https://jobtrackr-frontend-tan.vercel.app

---

## Tech Stack

* React (Vite)
* TypeScript
* Tailwind CSS
* React Router

---

## Features

* Authentication (Login)
* Dashboard overview
* Applications management (Create, Edit, Delete)
* Clean and responsive UI
* Toast notifications and loading states
